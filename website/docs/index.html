AETHER / USER GUIDE

Get moving, not configuring.

The essentials for server managers, dispatchers and officers. No hosting setup or developer credentials required.

GET STARTED IN MINUTES

Set up your shift.

Your Discord permissions determine which tools you can use. Aether keeps dispatch, officer records and server management connected.

01 / SERVER OWNER

Add Aether

Invite Aether to your Discord server, then select it from the Aether dashboard.

Open dashboard ↗
02 / CAD MANAGER

Choose how CAD works

Run /cad interface to choose Discord, Web or Hybrid. You can also change this in the CAD manager settings.

Open CAD ↗
03 / DISPATCH

Prepare your team

Assign CAD access roles and a dispatch channel. Officers set their callsign and duty status with /cad unit.

04 / GO LIVE

Run your first scenario

Use /911 for fictional calls, respond from Discord or the web, and search MDT records as required.

Browse commands ↗
ONE DATABASE, THREE WAYS TO WORK

Pick the setup that fits your team.

The mode changes your preferred interface, not the underlying CAD data or Discord permissions.

01

Discord-first

Great for small teams who want fast commands, rich incident cards and short roleplay sessions.

/cad interface mode:DiscordDispatch alerts, Respond buttons, BOLO lookups
02

Web CAD

Best for staffed departments using a full screen, unit roster, ER:LC map and officer MDT.

/cad interface mode:WebAuthenticated browser, map and incident board
03 / RECOMMENDED

Hybrid

Web dispatchers and Discord officers work together without duplicate records or different case IDs.

/cad interface mode:HybridBoth interfaces share incident and audit data
FOR YOUR STAFF

Useful shortcuts.

/cad callsCheck the dispatch queue
/cad mdt searchFind fictional people, vehicles and BOLOs
/cad panicIssue a priority roleplay alert when on duty
/cad bolo addIssue an active lookout alert
/cad unitUpdate callsign and availability
/cad dashboardOpen the connected web workflow
