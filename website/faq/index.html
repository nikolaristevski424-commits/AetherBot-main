Support / frequently asked

The details matter.

Answers about security, CAD, Discord authorization, privacy and getting started.

What does the website actually control?

The dashboard reads server-specific information from your Wispbyte-hosted Aether bot. The CAD supports roleplay calls, units, and fictional MDT/BOLO records. Staff actions require live Discord permissions.

What do I need for Discord login?

Add the exact website OAuth redirect URL in your existing Discord application and set AETHER_DISCORD_CLIENT_ID, AETHER_DISCORD_CLIENT_SECRET and AETHER_SESSION_SECRET on Vercel.

Can people access another server’s private data?

The bot checks each user’s current Discord membership and authorized roles for every private request. A cookie alone never grants permission.

Is the CAD available without Wispbyte?

The public CAD page and design are available, but real incident data and commands require a reachable Wispbyte HTTPS backend and a shared bridge secret.

Does it show real player locations?

Only when the ER:LC API supplies player coordinates. Positions are snapshots and can become stale. Map calibration should be checked at known in-game locations.

Are 911 calls real emergency calls?

No. Everything in the dispatch system is for fictional Roblox ER:LC roleplay. For actual emergencies, contact your local emergency services.

Can I manage warnings and timeouts online?

The staff desk supports authorized warning and timeout workflows once the website bridge is connected. Discord permissions and moderation hierarchy still apply.

Can I change the visual theme?

Aether’s public site has a consistent blue-violet design. More per-server branding is possible in future dashboard updates.

Do I need to provide my bot token to the website?

No. Never paste your bot token into a web page. It stays on Wispbyte and is not sent to the browser or Vercel.

Where is the original source?

Your Aether source and deployment instructions are available in the linked GitHub repository. The website is a separate frontend connected to that same bot.
