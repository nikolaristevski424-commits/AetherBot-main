Having trouble signing in?

The Aether website and Wispbyte CAD use separate OAuth callbacks. Both must be registered on the same Discord application and have their own environment configuration.

https://aetherbot-hq.vercel.app/api/auth/callback https://aether.wispbyte.app/cad/auth/callback

Finish authorization in the same browser and hostname where you started. If it fails again, the message above identifies whether it is a cookie/state, Discord credential, or connection problem.
