Command directory

Right where you need it.

A few of the everyday commands that power Aether. Command availability depends on Discord permissions and enabled modules.

Browse Aether's featured commands.

/cad setup

Server managers choose Discord, Web or Hybrid using an interactive setup menu.

/cad interface

View or change your server's preferred CAD experience.

/cad panic

On-duty officers can send a high-priority roleplay alert to dispatch.

/911

Create an in-game roleplay emergency call with location and details.

/cad calls

See active cases and current dispatch workload.

/cad map

Render a Liberty County map with player positions and 911 call pins.

/cad unit

Set your on-duty status and callsign.

/cad mdt search

Search fictional person and vehicle records.

/cad bolo add

Issue a roleplay BOLO.

/cad base join

Connect the optional voice alert station.

/warn

Issue a moderation warning with a reason.

/timeout

Apply a time-limited moderation action.

/ticket

Access your server ticket system.

/erlc setup

Configure ER:LC private-server integration.

/help

Explore commands registered by the bot.

The exact command list is maintained by the bot. Some commands require server configuration, the ER:LC API pack, or CAD access.
