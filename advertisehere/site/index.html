GOOD TO KNOW

Questions,
answered.

Simple rules. Fair exposure. A directory designed to stay useful for everyone.

How often can I bump my server?+

Every approved server can be bumped once every two hours. Bumping on the website and in Discord uses the same cooldown, so nobody can bypass it.

Does listing my server cost anything?+

Basic directory listings are free. You can submit a server you manage, and it will appear after review.

Why are listings reviewed?+

Review keeps the directory relevant and reduces spam. Listing owners must supply a working Discord invite belonging to their server.

Do I need to install the bot?+

Yes. AdvertiseHERE uses Discord server permissions and its bot to verify who can edit, submit, and bump a listing.
