to discovered.

Everything you need to submit a server and start growing on AdvertiseHERE.

01 / CONNECT02 / CREATE03 / REVIEW04 / BUMP
01 / CONNECT

Use your Discord account.

Keep using the Discord server you already have. Install AdvertiseHERE and sign into the dashboard. You'll only see servers you manage where the bot is present.

Go to dashboard ↗
02 / CREATE

Make your listing useful.

Choose a category, add a clear description and supply a Discord invite for the same server. Don't impersonate another community or advertise misleading content.

Open listing studio ↗
03 / MODERATION

Wait for approval.

Each listing enters a review queue. Your server stays private from the directory until staff approve it. Editing an approved listing sends it through review again.

Read platform standards ↗
04 / BUMP

Make your next move.

After approval, bump using /bump in Discord or the dashboard. The same two-hour cooldown applies to both methods, with no loopholes.
