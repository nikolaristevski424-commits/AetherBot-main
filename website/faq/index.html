Support / frequently asked

The details matter.

Answers about security, CAD, Discord authorization, privacy and getting started.

What does Aether do?

Aether combines Discord moderation, tickets, ER:LC utilities, staff workflows and a roleplay dispatch CAD. The website makes those features easier to manage.

How do I choose Discord CAD or Web CAD?

A server manager can run /cad interface or open CAD Settings to select Discord-first, Web-first or Hybrid. The choice can be changed later without deleting calls or fictional records.

Can dispatchers use the web while officers use commands?

Yes. Hybrid mode is designed for that. Calls, units, BOLOs and records are stored together and each action still requires the appropriate Discord roles.

What happens when someone sends /911?

Aether creates a fictional incident, sends an interactive dispatch alert to the configured channel and lets authorized units respond. Managers can close cases. All activity is stored in the CAD.

Does it have a panic button?

An on-duty unit can use /cad panic to create a priority roleplay call. Aether prevents repeated open panic alerts from the same user within a short window.

Where are the full CAD and officer MDT?

Open Aether CAD for the standalone dispatch, map and MDT workspace. The main website also has a connected operations dashboard.

Do officer records contain real personal information?

No. MDT and BOLO records are intended only for fictional Roblox roleplay. Do not enter real addresses, birthdays, sensitive details or unrelated personal information.

How accurate is the player map?

It uses periodic ER:LC private-server API snapshots where available. Positions may become stale between updates, and no actual GPS tracking is claimed.

Why can't I use a CAD command?

Your server may require an assigned CAD role, on-duty status, or Manage Server permission. Ask a server manager to check your Discord access and CAD settings.

Can I use Aether on a phone?

The main website, CAD and companion have responsive interfaces. The ER:LC companion is also an installable browser app on supported devices.

Can I switch between light and dark mode?

Yes. The theme button keeps your choice on your device, and the website follows your system preference until you choose otherwise.

Is this a real emergency service?

No. Every 911 call, BOLO, panic and dispatch action is solely for Roblox ER:LC roleplay. For real emergencies, call your local emergency number.
